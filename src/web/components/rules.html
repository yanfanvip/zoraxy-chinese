www.aroz.org

目标需要 TLS
上游 TLS 要求

勾选 代理目标需要 TLS 连接 表示上游服务器（你代理到的目标）要求使用 HTTPS。
与客户端访问本代理使用 HTTP 还是 HTTPS 无关。

示例
匹配关键词：mydomain.com
目标：example.com:443（已启用 TLS）
  • 客户端访问 mydomain.com（HTTP 或 HTTPS 由代理配置决定）
  • 代理以 HTTPS 转发到 example.com:443
若上游仅接受安全连接可勾选此项。
若上游使用自签名证书，请在高级设置中勾选 忽略 TLS/SSL 验证错误。
什么是粘性会话？
粘性会话（会话保持）

粘性会话保证同一客户端的请求始终转发到同一上游。适用于在本地保存会话、需要客户端固定连到同一后端的应用。

如何添加多个上游
  • 在侧栏进入 HTTP 代理。
  • 在对应代理规则上点击 编辑。
  • 在 上游 中添加多个上游端点以实现负载均衡。
仅当配置了多个上游时粘性会话才会生效。
