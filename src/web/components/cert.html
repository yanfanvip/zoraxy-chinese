关于服务器名称与 SNI

若有 a.example.com 和 b.example.com 等子域名，为加快响应可分别配置证书。
若有覆盖 *.example.com 的通配符证书，只需将服务器名称填为 example.com 即可添加。
若证书包含多个主机名，可只填证书中的第一个域名，Zoraxy 会尝试匹配其余 CN/DNS。

什么是回退证书？

当反向代理无法为请求的服务器名称找到匹配证书时，将使用回退证书。若使用 CloudFlare 完全严格模式，可将 CloudFlare 证书上传为回退证书。
